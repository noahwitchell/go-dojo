# Go Dojo — notes for Claude

- Owner: Noah. Phone Go practice tool: Play (MCTS computer, 9/13/19, handicap, coach), Drills, Capture Go, Learn.
- Look = Coffea Arabica house style (~/Claude/Coffea): flat paper + ink, DM Serif Display, 1.5px ink outlines, pill buttons, no gradients/shadows/blur, light-only. Stones flat: solid top + offset solid side face.
- Edit `index.src.html`, `engine.js`, `problems.js`; then `python3 build.py` (writes `index.html` for Pages and `artifact.html` for the claude.ai artifact https://claude.ai/artifact/NpURz6NPeAyMdJ5vQhc8zx — republish with that `url`).
- Drills: you always play Black. Hand-made intro drills live in `problems.js` (`node verify.js` must show the intended answers). The library (~100 per idea: ladder, net, atari, throwin, race, escape, kill, live) is `drills.gen.js`, generated by `tools/gen_drills.js`: random motif positions, kept only when the solver proves Black's goal works, passing fails, and only 1-2 moves work; classified by the solver's main line (all-atari 3+ runs = ladder, non-atari answer = net, self-atari answer = throw-in). Run parallel parts with `ONLY=<ideas> SEED=<n> OUT=<part.json> node tools/gen_drills.js <per>` then `MERGE=<parts,...> ONLY=none node tools/gen_drills.js 100` (dedupes by symmetry + local shape). Capture ideas are slow (nets ~10 min per 16).
- Play handicap: 0 = even (7.5 komi), 1 = Black first with 0.5 komi, 2-9 = stones.
